## Backend instructions 

The apis shoule be secure and scalable, every ai based task will be triggered using the inngest. The front end will not directly call the ai based apis, instead it will call the inngest apis which will trigger the ai based tasks in the backend. use webhooks to get the status of the task and update the database. Use redis for caching, rate limiting and pub/sub.



use typescript for backend development 
use express for backend development 
use postgres for backend development 
use redis for backend development 
use inngest for backend development 
use fal.ai and openrouter for backend development 

use jwt for authentication and authorization 
use bcrypt for password hashing 
use Zod for data validation
